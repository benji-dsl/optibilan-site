# i18n de la vitrine (FR / EN)

Le site est statique (Astro + Cloudflare Pages). Chaque page existe en deux fichiers :

| Français (défaut) | Anglais |
| --- | --- |
| `src/pages/pricing/index.astro` → `/pricing/` | `src/pages/en/pricing/index.astro` → `/en/pricing/` |

Les **slugs sont identiques** dans les deux langues. Une seule règle : préfixer par
`/en`. Aucune redirection à maintenir, aucun slug traduit à mapper.

## Ce qui est automatique

- `src/i18n/config.ts` : `normalizePath()`, `localizePath()`, `localeOf()`.
- `src/layouts/Layout.astro` : `<html lang>`, `og:locale`, JSON-LD `inLanguage`,
  canonical, **et les trois `hreflang`** (fr, en, x-default → fr).
- `Header`, `Footer`, `Hero`, `CTA`, `Pricing`, `TrustBar`, `LanguageSwitcher`
  lisent `Astro.currentLocale` : une page sous `/en/` rend automatiquement la
  version anglaise de l'ossature, avec les liens internes préfixés.
- `src/i18n/routes.ts` (`EN_ROUTES`) : la liste des pages qui existent en anglais.
  Le `hreflang="en"` n'est émis que si la page existe vraiment (pas de soft 404).
- Sitemap : `@astrojs/sitemap` reçoit `i18n` dans `astro.config.mjs` et écrit les
  alternates `xhtml:link` dans `sitemap-index.xml`.

## Créer une page anglaise : la checklist

1. Même arborescence que la page française, sous `src/pages/en/`.
2. Ajouter le chemin canonique (forme FR) à `EN_ROUTES` dans `src/i18n/routes.ts`.
3. `<Layout lang="en" canonical="/en/<chemin>/">` — le canonical est l'URL anglaise.
4. **Tous les liens internes** passent par `lp('/chemin/')` :
   ```astro
   import { localizePath } from '../../i18n/config';
   const lp = (href: string) => localizePath(href, 'en');
   ...
   <a href={lp('/product/nutrition/')}>Nutrition</a>
   ```
   `Header`, `Footer`, `CTA` et `Hero` localisent déjà leurs propres liens.
5. Le `jsonLd` passé par la page est traduit : `inLanguage: 'en-US'`, noms de
   fil d'Ariane en anglais, `item` vers `/en/...`.
6. Les CTA passés en props à `Hero` / `CTA` restent en chemins canoniques FR
   (`'/pricing/'`) : le composant les préfixe lui-même.

## Règles de traduction

- B2B, vouvoiement d'usage américain : « you ».
- `bilan` → **check-in** · `coaché` → **client** · `cabinet` → **practice**
  (ou **clinic** quand c'est médical) · `marque blanche` → **white label**
  · `préparation mentale` → **mental preparation** · `adhérence` → **adherence**.
- Noms propres, prix, chiffres et noms de modules ne changent pas.
- Aucun tiret cadratin (—) dans les textes : point, virgule ou deux-points.
- Ne rien inventer : aucune promesse, aucun chiffre, aucun label de conformité qui
  ne soit pas dans la version française.
- Les pages légales portent en tête la mention : « Courtesy translation. The French
  version prevails in case of discrepancy. »
